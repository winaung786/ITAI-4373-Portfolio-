# 🏗️ Frameworks & Libraries

## Deep Learning Frameworks

### PyTorch
**Level:** Intermediate to Advanced

**Core Components:**
- `torch.nn` - Neural network modules
- `torch.optim` - Optimization algorithms
- `torch.utils.data` - Dataset and DataLoader utilities
- `torchvision` - Computer vision datasets and models
- `torchaudio` - Audio processing
- `torchtext` - Text processing utilities

**Key Features:**
- Dynamic computational graphs
- Pythonic and intuitive API
- Strong GPU acceleration
- Extensive pre-trained models
- Active research community

**Applications:**
- Custom neural network architectures
- Computer vision projects
- Natural language processing
- Research prototyping
- Transfer learning

### TensorFlow & Keras
**Level:** Intermediate

**Core Components:**
- `tf.keras` - High-level API for building models
- `tf.data` - Input pipeline building
- `tf.nn` - Neural network operations
- `tf.image` - Image processing
- `tf.text` - Text processing

**Key Features:**
- Production-ready deployment
- TensorFlow Serving for APIs
- TensorFlow Lite for mobile/edge
- TensorBoard for visualization
- Cross-platform support

**Applications:**
- Production ML systems
- Mobile and edge deployment
- Scalable training pipelines
- Model serving and APIs
