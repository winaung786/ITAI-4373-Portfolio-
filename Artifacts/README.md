# 🗂️ Artifacts Directory

This directory contains supporting materials, outputs, and artifacts from various projects and coursework.

## 📂 Folder Structure

### 📸 Images (`images/`)
Contains visual assets including:
- Project screenshots
- Result visualizations
- Diagrams and flowcharts
- Model architecture images
- Demo GIFs
- Performance graphs
- Comparison charts

**Recommended Formats:** PNG, JPG, GIF, SVG

### 📄 PDFs (`pdfs/`)
Contains document artifacts including:
- Project reports
- Research papers
- Technical documentation
- Assignment submissions
- Certificates
- Datasheets

**Format:** PDF

### 📊 Presentations (`presentations/`)
Contains presentation materials including:
- PowerPoint/Keynote files
- PDF presentations
- Slide decks
- Demo videos
- Pitch materials

**Recommended Formats:** PDF, PPTX, KEY, MP4

---

## 📝 Usage Guidelines

### Adding New Artifacts

1. **Images**
   ```bash
   # Place images in appropriate subfolder
   Artifacts/images/project1_results.png
   Artifacts/images/model_architecture.jpg
   ```

2. **PDFs**
   ```bash
   # Add PDFs with descriptive names
   Artifacts/pdfs/project1_report.pdf
   Artifacts/pdfs/research_paper.pdf
   ```

3. **Presentations**
   ```bash
   # Store presentation files
   Artifacts/presentations/midterm_presentation.pdf
   Artifacts/presentations/final_demo.pptx
   ```

### Naming Conventions

Use descriptive, consistent naming:
- **Good:** `deeplearning_project1_accuracy_graph.png`
- **Good:** `nlp_sentiment_analysis_report.pdf`
- **Bad:** `image1.png`
- **Bad:** `doc.pdf`

### File Size Considerations

- Keep images optimized (< 2MB when possible)
- Compress PDFs if large
- Use appropriate resolution for images
- Consider using external hosting for large videos

```markdown
![Project Results](../Artifacts/images/results.png)

```

### Relative Paths
Always use relative paths from the current file location:
- From project folder: `../../Artifacts/images/image.png`
- From main README: `Artifacts/images/image.png`

## 🎨 Best Practices

### For Images
1. Use descriptive filenames
2. Optimize file sizes
3. Use consistent dimensions
4. Include alt text in markdown
5. Organize by project/topic

### For PDFs
1. Ensure documents are searchable
2. Include metadata (title, author)
3. Compress large files
4. Use bookmarks for navigation
5. Ensure accessibility

### For Presentations
1. Export to PDF for compatibility
2. Include presenter notes
3. Test on different devices
4. Keep file sizes manageable
5. Include source files when possible

### What NOT to Include
- ❌ Personal sensitive information
